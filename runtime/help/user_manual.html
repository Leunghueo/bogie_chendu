1　软件概述

本程序用于 XLT 静载试验台的数据采集、试验流程控制、设备状态监控与参数配置，面向转向架静载试验的全过程：创建试验工单 → 按流程自动执行加载、测量与空气弹簧试验 → 生成结果 → 导出报告 / 上传 EMIS。

程序同时连接三路数据源：

数据源作用
PLC试验台控制与采集：加载压力、压头垂向位移、气压采集、液压系统、动作指令与完成信号等
VSP串口服务器采集：称重（轮重）、激光测距（车轮内测距、轮高）、压头横向位移等
CANCAN 总线采集点位

任一路可在配置文件 app.ini 中单独启用/停用（enable=true/false），停用的一路不加载、不轮询，状态栏显示“未启用”。

2　启动与登录

运行程序（打包版为与 runtime 文件夹同级的 main 程序；源码版运行 python main.py）后，首先弹出登录窗口：

图 1　登录窗口

  1. 在“用户名”下拉框中选择用户（用户在用户库中维护，见第 10 节）；
  2. 输入密码，点击 登录 进入主窗口；点击 取消 则退出程序；
  3. 用户名或密码错误会弹出“登录失败”提示，请核对后重试。

权限：admin（管理员）可打开“设置”菜单的全部配置页和“用户管理”；普通用户打开时会提示“权限不足”。登录后如需换人操作，点击主窗口右下角的 当前用户：xxx 按钮重新登录即可，不必重启程序。

3　主窗口概览

图 2　主窗口 · 试验流程页

  • 顶部菜单：设置、工具、帮助三个下拉菜单（详见第 9、10 节）；
  • 页签区：试验流程、实时监控、实时测量、空气试验界面、历史记录五个页面，点击页签切换；
  • 底部状态栏：PLC / VSP / CAN 三路在线状态（绿色在线、红色离线、灰色未启用）、故障信息、当前用户。其中 双击“故障信息”可打开日志查看器，查看当天及历史日志（可勾选“显示完整日志”，默认过滤 INFO 级别）；
  • 试验流程页顶部状态条：集中显示手动/自动、防沉开/关状态，加载压力、压头位移、气压、车轮位移、车轮内测距、轮高等等关键量，右侧红色按钮为 紧急停止。

4　试验流程（核心操作）

试验流程页是日常操作的主页面，左侧为“流程编辑 / 控制区”，右侧为流程展示区。

4.1　创建工单

  1. 在左侧依次选择 车型、位号、流程，填写 车号、编号。试验单号由“车型-位号-车号-编号-流程”自动拼成；
  2. 点击 创建工单，在确认弹窗中核对参数后点击 确认创建；
  3. 工单一经创建即写入作业库（状态“未开始”），并出现在下方“当前工单”列表中。程序重启后，当天工单会自动从作业库恢复显示。

4.2　工单列表与状态

列表列为：状态 / 试验单号 / 时间 / 操作员。整行颜色表示状态：

颜色状态说明
灰色未开始已创建，未执行
蓝色执行中流程正在运行
绿色已完成流程完成且已有结果，只读
橙色未完成（停止 / 无结果 / 中断）中途停止、断电或程序退出造成的未完成，可重新开始续跑
红色未完成（故障）流程执行故障，只读，请先查故障信息与日志

选中某个工单，右侧同步显示它的流程图和节点状态；点击右上角 切换到表格视图 / 切换到流程图 可在两种展示间切换；点击 展开数据 / 查看数据详情 可展开数据面板查看试验参数与过程数据。

4.3　开始 / 停止试验

  1. 选中工单，点击 开始试验。未开始、停止、中断状态的工单都在原记录上运行（续跑时上一轮结果会被新一轮刷新）；已完成和故障工单不可启动；
  2. 流程自动按节点执行。运行中如遇 选择节点，会弹出分支选择框供操作员选支路；之后想改选时，点击 选择指令 可重新打开选择框。遇 等待节点 会显示倒计时，需要时可点 跳过等待；
  3. 需要中止时点击 停止试验，工单记为未完成（停止），之后可再次开始；
  4. 流程跑完且结果汇总完成后，工单变为已完成（绿色）。

4.4　查看与补录结果

双击列表中的工单（或在历史记录页，见第 8 节）打开结果数据窗口：按项目列出测量值。未开始的工单显示的是按车型模板生成的空表；已停止的工单显示已测到的数据。在结果窗口修改数值并确认后，会按补录方式回写作业库并留下补录痕迹，取消则不写入。

4.5　删除工单

选中工单点击 删除工单，确认框默认选“否”，确认后工单及其作业库记录一并删除，不可恢复，请谨慎操作。运行中的工单不能删除。

4.6　紧急停止

发生异常需要立即停机时，点击页面顶部红色 紧急停止 按钮，确认后程序向 PLC 写入停止信号。紧急停止只用于异常情况，日常停试验请用“停止试验”。

5　实时监控

图 3　实时监控页（PLC 页签）

实时监控页即点位总表，页签分 PLC / VSP / CAN 三路。顶部显示三路连接状态与最后轮询时间；勾选 完整模式 后额外显示“分段系数”和“描述”列。

  • PLC 页签：左栏“读取 (Input)”、右栏“写入 (Output)”，列为名称 / 类型 / 地址 / 单位 / 原始值 / 计算值。计算值 = 原始值经分段系数（segs）换算再加偏移（add）的结果；显示 ERR 表示该点最近一轮采集失败；
  • 双击输出点（PLC）：BOOL 型直接翻转写入，非 BOOL 型弹窗输入数值后写入；
  • 双击输入点（PLC）：打开该点的标定弹窗；按住 Ctrl 双击则直接写值（跳过动作确认）；
  • VSP / CAN 页签：只读采集，双击点位打开标定弹窗。标定弹窗中可编辑该点的分段标定点（采集值→计算值）与偏移 add，保存后写回配置文件并即时对运行中的点位生效；“标零”仅预填偏移值，确认无误后点保存才生效。

6　实时测量

图 4　实时测量页

实时测量页以转向架示意图直观显示各测量点位置与读数（轮重测量、车轮内侧距、称重台 X 位移等）。

  • 顶部单选 显示传感器 / 显示计算结果，在原始传感器读数与计算结果之间切换；
  • 图中蓝色标签为校准入口：各轮 内测距校准 与 1-3 / 2-4 零点校准，点击后按提示完成对应校准；
  • 右下角“锁”标识表示当前锁定状态。

7　空气试验界面

图 5　空气试验界面

空气试验界面用于空气弹簧保压与差压试验的过程监视，试验未进行时显示“当前试验：未开始”。

  • 加载数据（初始 / 当前）：垂向位移 ①②（mm）、加载力 ①②（kN）的初始值与当前值对照；
  • 空气弹簧气压曲线：黄色为空簧 1 气压、红色为空簧 2 气压，横轴保压时间（min）、纵轴气压（kPa），保压过程中自动绘制；
  • 空簧保压：空簧 1/2 的初始气压、保压后气压与泄漏量（kPa）；
  • 差压 1→2 / 差压 2→1：两个方向差压试验的空簧气压与当前差压。

保压曲线数据会随试验结果一同保存，在历史记录中导出报告时附在报告 PDF 的单独一页中（见第 8 节）。

8　历史记录与报告

图 6　历史记录页

从页签或 工具 → 历史记录 进入。

  1. 查询：在“日期”框输入日期（支持 2026-09-27 或 20260927 两种格式），点击 搜索；点 刷新 重新加载。列表仅显示已有结果数据的作业，列为日期 / 类型 / 名称 / ID / 上传EMIS 状态；
  2. 查看结果：在列表中选中一条作业，下方“所选日志结果列表”显示其结果明细：项目 / 测量值 / 最小值 / 最大值 / 单位 / 结论；
  3. 导出报告：选中作业点击 导出报告，按报告模板生成 PDF（保压曲线有数据时自动在报告后附单独一页曲线图），文件保存在 runtime/pdf 目录；打印 按钮生成同一 PDF 并送打印机；
  4. 上传 EMIS：把所选作业结果上传至 EMIS 系统，成功后列表的“上传EMIS”列会标记已上传及时间，重复上传前请确认；
  5. 补录数据：选中作业点击 补录数据，在弹窗中修改结果数值并保存，修改会留痕（补录标记）；没有结果数据的作业不能补录。

9　设置菜单（管理员）

“设置”菜单的四项均为 JSON 配置编辑器，仅管理员可打开，修改后保存即写回对应配置文件：

菜单项配置文件内容
转向架设置runtime/device/bogies.json车型目录：位号、试验参数、原点与结果模板等
静载试验台设置runtime/device/bed.json试验台数据：设备编号、原点位置、安全检查等
PLC设置runtime/hardware/plc.jsonPLC 点表：地址、类型、分段系数、动作与完成条件等
信息化设置runtime/push/config.jsonIoT / EMIS 推送配置（地址、口令、间隔等）

注意：配置文件直接决定设备动作与计算结果，修改前请先备份原文件；口令类字段切勿外传或提交到公开渠道。VSP 点表（runtime/hardware/vsp.json）与 CAN 点表不在菜单中，如需修改请由管理员直接编辑文件后重启程序。

11　状态判断与常见问题

现象判断与处理
状态栏某路显示“未启用”该路在 app.ini 中 enable=false，属配置行为，不是故障；需要时由管理员改配置后重启
状态栏某路“离线”，点位计算值 ERR通信中断：检查设备上电、网线与交换机、配置文件中的 IP/端口；恢复后自动重连
原始值有数字、计算值 ERR原始值是上一轮的残留值，本轮采集失败即会如此，不能据此认为本轮正常；先排查该点通道
多个 VSP 点位同时恒 ERR常见原因是两台电脑同时访问同一采集设备造成冲突，停掉另一台后恢复；再查单个点的 error 信息
双击故障信息打开日志查看器定位故障时间点，处理时请把日志文件一并发给维护人员
工单无法开始试验已完成 / 故障状态工单为只读；另请确认 PLC、VSP 已在线且无安全检查报警
登录失败核对用户名与密码；忘记密码请管理员在“用户管理”中重置
试验中程序被关闭 / 断电重新启动后工单显示为未完成（中断，橙色），选中后可点“开始试验”在原记录上续跑
